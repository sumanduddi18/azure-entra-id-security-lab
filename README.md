# Microsoft Entra ID Security Lab

Hands-on Microsoft Entra ID security and Identity & Access Management (IAM) lab built on Microsoft Azure.

## 🎯 Objectives

- Manage users, groups and Administrative Units
- Implement Azure RBAC and least-privilege access
- Configure Enterprise Applications and App Registrations
- Implement Managed Identity and Service Principal authentication
- Review Sign-in, Audit and Activity Logs
- Practice identity security and monitoring scenarios
