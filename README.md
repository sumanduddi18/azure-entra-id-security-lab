# Microsoft Entra ID Security Lab

Hands-on Microsoft Entra ID security and Identity & Access Management (IAM) lab implemented using Microsoft Azure.

## 🎯 Objectives

- Manage Microsoft Entra ID users, groups and Administrative Units
- Implement Azure RBAC and least-privilege access
- Configure Enterprise Applications and App Registrations
- Implement Service Principal and Managed Identity authentication
- Monitor identity and resource activity using Azure logs
