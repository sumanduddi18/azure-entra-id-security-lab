# 🛡️ Project 02 – Microsoft Defender for Cloud

## Cloud Security Posture Management (CSPM) & Cloud Workload Protection Platform (CWPP)

---

# 📖 Project Summary

Microsoft Defender for Cloud is Microsoft's cloud-native security solution that helps organizations continuously assess, protect, and improve the security posture of their cloud environments. It combines Cloud Security Posture Management (CSPM) and Cloud Workload Protection Platform (CWPP) capabilities to identify security risks, monitor cloud resources, and provide actionable remediation recommendations.

In this project, I implemented Microsoft Defender for Cloud in a simulated enterprise Azure environment using a Pay-As-You-Go subscription. The implementation included enabling Microsoft Defender for Cloud, configuring Defender Plans, reviewing Secure Score, analyzing Security Recommendations, evaluating Regulatory Compliance, monitoring Security Alerts, validating protected resources, and performing complete resource cleanup to optimize Azure costs.

# 🏢 Business Scenario

A financial organization has recently migrated its workloads to Microsoft Azure. The security team requires centralized visibility into the security posture of cloud resources while ensuring regulatory compliance and protecting workloads against potential threats.

Microsoft Defender for Cloud was implemented to continuously assess Azure resources, identify security misconfigurations, prioritize remediation activities, improve Secure Score, monitor cloud workloads, and strengthen the organization's overall cloud security posture.

This project simulates that enterprise implementation using Microsoft Azure.
